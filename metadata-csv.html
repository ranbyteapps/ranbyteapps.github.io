What CSV metadata workflows are for

A CSV file is a simple spreadsheet-friendly text file. It can hold rows for filenames and columns for captions, descriptions, tags, or other metadata fields. This makes it useful when you want to review many files at once instead of opening each image individually.

  • Export image metadata to a CSV file for review.
  • Open exported metadata in a spreadsheet app.
  • Review filenames, captions, descriptions, and other available fields.
  • Prepare or edit descriptions in a table-style workflow.
  • Import descriptions or captions back into supported images where available.
  • Use CSV as a simple record of an image archive or project folder.
  • Work locally without uploading images to an online metadata service.
Local-first note: CSV metadata workflows happen with files you choose on your computer. You do not need to upload private photos, scans, or archives to an online metadata tool.

How to export image metadata to CSV

  1. Open the metadata tools.
    In Grafiq, open the metadata feature area, such as Metadata Explorer or the available metadata export workflow.
  2. Choose the folder or files.
    Select the image folder or image files you want to review.
  3. Run the metadata scan.
    Let Grafiq read available metadata from the selected files.
  4. Review the results.
    Check that the files and fields look reasonable before exporting.
  5. Export to CSV.
    Use the CSV export option and choose where to save the CSV file.
  6. Open the CSV in a spreadsheet app.
    Review the exported rows and columns in Excel, Numbers, LibreOffice, Google Sheets, or another spreadsheet tool.
Simple rule: Export first, review the CSV, and keep that CSV as a reference before doing large metadata edits.

How to import descriptions from CSV

  1. Prepare your CSV file.
    Make sure the CSV includes a filename or file path column and a description or caption column that Grafiq can match.
  2. Keep filenames stable.
    Do not rename or move the image files between exporting the CSV and importing it back, unless your CSV uses updated paths.
  3. Open the import workflow.
    In Grafiq, choose the available option to import descriptions or metadata from CSV.
  4. Select the CSV file.
    Choose the prepared CSV file.
  5. Map or confirm fields if prompted.
    Confirm which CSV column contains filenames and which column contains captions or descriptions.
  6. Run the import.
    Let Grafiq apply matching descriptions to supported files.
  7. Check a few files.
    Open several updated images and confirm the imported text landed where expected.

Good uses for metadata CSV files

  • Create captions for a folder of scanned family photos.
  • Review image descriptions in a spreadsheet before importing them.
  • Keep a simple archive list of filenames and captions.
  • Share a metadata review sheet with someone helping identify people or places.
  • Find missing captions or incomplete descriptions.
  • Prepare image metadata before using Rename Files or Organizer.
  • Export a record of metadata before stripping or editing fields.

Suggested CSV workflow for scanned photos

  1. Split scanned photo sheets first.
    Use Photo Splitter if your scanner created pages containing multiple photos.
  2. Rename files into a clean sequence.
    Use Rename Files or Organizer so the image filenames are stable and easy to review.
  3. Export metadata to CSV.
    Create a spreadsheet-style list of the image files.
  4. Add captions or descriptions in the CSV.
    Fill in names, dates, places, events, or notes.
  5. Import descriptions back into Grafiq.
    Apply the CSV captions or descriptions to the matching files where supported.
  6. Optionally add visible captions.
    Use Image Caption & Overlay if you also want visible text on exported copies.

CSV tips

  • Keep a backup copy of the CSV before editing.
  • Keep filenames and paths consistent between export and import.
  • Use short, clear column names.
  • Avoid changing filename extensions in the CSV unless you also changed the actual files.
  • Be careful with commas inside captions if your spreadsheet app changes CSV formatting.
  • Test with a few files before importing a large CSV.

CSV metadata vs. visible captions

  • CSV metadata workflow: Best for reviewing and importing embedded descriptions or captions across many files.
  • Visible caption overlay: Best when you want text drawn directly onto an exported image.
Good workflow: Use CSV metadata for archive organization and searchable descriptions. Use visible caption overlays when the text needs to appear directly on the image.

What to watch out for

  • Not every image format supports every metadata field.
  • Metadata import depends on matching the CSV row to the correct file.
  • If files are renamed after exporting the CSV, imports may not match.
  • Spreadsheet apps can sometimes reformat text, dates, or special characters.
  • Keep originals and backups before running large metadata imports.
  • After importing, check a few files before assuming the whole batch is correct.
  • CSV export may include fields that are useful for review, but not every exported column can currently be imported back as an editable field. For CSV import, focus on supported fields such as title, author, description, copyright, software, and new_filename.
