Grafiq

Available now

Grafiq is a local-first desktop utility for Mac and Windows. It includes tools for working with images, videos, GIFs, metadata, scanned photos, file organization, classic resizing/upscaling, conversion, redaction, cropping, and other everyday media tasks.

Grafiq is designed to be simple and affordable:

  • No subscriptions
  • No ads
  • No accounts required
  • No watermarks
  • Local processing by default

Grafiq Mac and Windows Versions

Grafiq is available for Mac and Windows. Most core tools are designed to work similarly across both versions, including conversion, metadata tools, crop tools, GIF/video tools, redaction, duplicate finding, organizing, photo splitting, downscaling, classic resizing/upscaling, and SVG tools.

Some features may vary by platform because macOS and Windows handle sandboxing, media tools, local AI libraries, file permissions, and bundled system components differently.

Grafiq on Apple Silicon and Intel Macs

Grafiq’s Torch-based local image tools, including Background Remover and RealESRGAN AI upscaling, are available on Apple silicon Macs where supported.

On Intel Macs, those Torch-based local image tools are not available in the Mac App Store version because of sandbox compatibility limits. Intel Macs can still use Grafiq’s other tools, including conversion, metadata tools, crop tools, GIF/video tools, redaction, duplicate finding, organizing, photo splitting, downscaling, classic resizing/upscaling, and non-Torch AI or internet features where available.

Common Grafiq Help Topics

Where do exported files go?

Many Grafiq tools ask you to choose an output folder. Some tools may create an Edited folder next to the original file, save exports next to the original file, or save exports to the folder you selected. Check the app log for the exact saved file path after an export finishes.

Does Grafiq upload my files?

Grafiq processes files locally by default. Optional AI or internet features are user-initiated. If you choose to use a third-party AI/API feature, selected content may be sent to the provider you configured. See the privacy policy for details.

How do I report inappropriate AI-generated output?

Grafiq may include optional AI-generated captions or descriptions when you choose to use AI features. If an AI-generated result is inappropriate, harmful, offensive, inaccurate, or otherwise problematic, you can report it from inside Grafiq by choosing:

Help → Report AI Output Issue

You may also email: ranbyteapps@gmail.com

Please do not include private images, passwords, API keys, or sensitive personal information unless needed for the report.

Why does a feature take time to open?

Some tools may load larger local processing libraries or models. Local image/video processing, background removal, AI upscaling, and video tools may take a few seconds to open or begin processing, depending on your computer and the selected file.

What file types does Grafiq support?

Grafiq supports many common media and document formats, including JPG, PNG, GIF, TIFF, WebP, HEIC/HEIF/AVIF where supported by the operating system, MP4, PDF, DOCX, XLSX, and SVG-related workflows. Support varies by tool and platform.

Does Grafiq edit MP3 or MP4 metadata?

Some audio/video metadata editing features may be limited or read-only to keep the app compatible with store and licensing requirements.

Reporting a Problem

When reporting an issue, please include:

  • App name, such as Grafiq
  • App version if known
  • Operating system version, such as macOS version, Windows version, or iOS version
  • Computer or device model if known
  • The feature you were using
  • The file type involved, such as JPG, PNG, GIF, MP4, PDF, DOCX, XLSX, or SVG
  • Any error message shown in the app

Do not email sensitive files unless you are comfortable sharing them.

Accessibility

Ranbyte Apps wants its apps and website to be usable by as many people as possible. Some app workflows involve visual previews, crop boxes, timelines, image regions, thumbnails, or photo review steps.

If you have trouble using any part of an app or this website, please email ranbyteapps@gmail.com and describe the page, app, feature, and issue so we can review it.
