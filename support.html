About Grafiq

Grafiq is a local-first photo, video, and file utility for Mac. It includes tools for working with images, videos, GIFs, metadata, scanned photos, file organization, classic resizing/upscaling, conversion, redaction, cropping, and other everyday media tasks.

Grafiq is designed to be simple and affordable:

  • No subscriptions
  • No ads
  • No accounts required
  • No watermarks
  • Local processing by default

Apple silicon and Intel Macs

Grafiq’s Torch-based local image tools, including Background Remover and RealESRGAN AI upscaling, are available on Apple silicon Macs.

On Intel Macs, those Torch-based local image tools are not available in the Mac App Store version because of sandbox compatibility limits. Intel Macs can still use Grafiq’s other tools, including conversion, metadata tools, crop tools, GIF/video tools, redaction, duplicate finding, organizing, photo splitting, downscaling, classic resizing/upscaling, and non-Torch AI or internet features where available.

Common Help Topics

Where do exported files go?

Many Grafiq tools ask you to choose an output folder. Some tools may create an Edited folder next to the original file or save exports to the folder you selected. Check the app log for the exact saved file path after an export finishes.

Does Grafiq upload my files?

Grafiq processes files locally by default. Optional AI or internet features are user-initiated. If you choose to use a third-party AI/API feature, selected content may be sent to the provider you configured. See the privacy policy for details.

Why does a feature take time to open?

Some tools may load larger local processing libraries or models. On Apple silicon Macs, local AI image tools such as Background Remover and RealESRGAN AI upscaling may take a few seconds to open or begin processing.

What file types does Grafiq support?

Grafiq supports many common media and document formats, including JPG, PNG, GIF, TIFF, WebP, HEIC/HEIF/AVIF where supported by macOS, MP4, PDF, DOCX, XLSX, and SVG-related workflows. Support varies by tool.

Does Grafiq edit MP3 or MP4 metadata?

In the Mac App Store version, some audio/video metadata editing features may be limited or read-only to keep the app compatible with App Store and licensing requirements.

Reporting a Problem

When reporting an issue, please include:

  • Grafiq version
  • macOS version
  • Mac model if known, such as Intel Mac or Apple silicon Mac
  • The feature you were using
  • The file type involved, such as JPG, PNG, GIF, MP4, or PDF
  • Any error message shown in the app

Do not email sensitive files unless you are comfortable sharing them.
