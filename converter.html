What Converter is for

Converter is useful when you need a file in a different format for sharing, editing, uploading, archiving, or compatibility. Instead of using several separate tools, Grafiq gives you a simple built-in conversion workflow.

  • Convert supported image files to JPEG, PNG, WEBP, BMP, or TIFF.

Local-first note: Grafiq is designed to process files locally by default. Optional internet or AI features are user-initiated, but normal file conversion does not require uploading your files to Ranbyte Apps.

Windows PDF-to-JPG workaround for Photo Splitter

On Mac, Grafiq Photo Splitter can open scanned PDFs directly. On Windows, Photo Splitter works from image files, so Converter can be used as a workaround when your scanner saved photo sheets as PDFs.

  1. Open Converter.
    Choose the scanned PDF you want to prepare.
  2. Convert the PDF page to JPG.
    Export the scanned page as a JPG image.
  3. Open Photo Splitter.
    Load the exported JPG into Photo Splitter.
  4. Split the photos.
    Run Auto-Detect, adjust crop boxes if needed, and export separate JPG or PNG files.
Why this matters: This gives Windows users a practical path for scanned photo sheets saved as PDFs: convert the PDF page to an image first, then split the photos from that image.

Good uses for Converter

  • Convert PNG, WEBP, HEIC, HEIF, AVIF, BMP, TIFF, or other supported image files into a more compatible format.
  • Convert videos to MP4 for easier sharing or playback.
  • Prepare image files for websites, documents, uploads, or archives.
  • Make image files easier to use in older apps that do not support newer formats.
  • Create JPG versions of scanned pages for Photo Splitter workflows.
  • Batch-convert files into a single output folder.

Tips for better conversion results

  • Use JPEG for normal photos when you want broad compatibility and smaller file sizes.
  • Use PNG when you want lossless output or need transparency support.
  • Use WEBP when you want modern web-friendly compression.
  • Use TIFF when you want an archival or editing-friendly image format.
  • Use MP4 for widely compatible video output.
  • Keep your original files until you confirm the converted results are correct.

What to watch out for

  • Not every format supports the same metadata, transparency, color, or compression behavior.
  • JPEG does not preserve transparency.
  • Video conversion re-encodes the file, so quality and file size may change.
  • Large video files can take time to convert.
  • For the simplest workflow, convert image files and video files in separate runs.
