What Find Image Duplicates is for

Find Image Duplicates is useful when you want to clean up image folders, reduce clutter, or review copied photo libraries. It groups likely duplicate or similar images so you can preview them and decide what to copy, move, or delete.

  • Find exact or near-exact duplicate images.
  • Find visually similar images using pixel similarity.
  • Scan a folder, with optional subfolder support.
  • Preview duplicate groups before acting.
  • Select files manually or use helper selection tools.
  • Copy, move, or delete selected duplicate files.
  • Use the Dashboard log to review actions.
Safety tip: Use Preview Selected before deleting anything. When in doubt, use Move Selected to move duplicates into a review folder instead of deleting them immediately.

How to find duplicate images in Grafiq

  1. Open Find Image Duplicates.
    In Grafiq, open Find Image Duplicates from the sidebar or menu.
  2. Choose a detection method.
    Start with the faster hash-based method for exact or near-exact duplicates. Use pixel similarity when you want to catch images that may have been resized, slightly edited, or visually similar.
  3. Choose the folder to scan.
    Click Browse and select the folder where your images are stored.
  4. Include subfolders if needed.
    Enable Include subfolders if your photos are stored inside nested folders.
  5. Start the scan.
    Click Find Duplicates. Grafiq scans the selected folder and groups likely matches.
  6. Review the groups.
    Look through the duplicate groups before selecting anything for cleanup.
  7. Preview selected files.
    Use Preview Selected to visually confirm that selected files are truly duplicates or close enough to remove.
  8. Choose what to do.
    Use Copy Selected, Move Selected, or Delete Selected depending on how cautious you want to be.

Hash match vs. pixel similarity

  • Hash Match: Fastest option. Best for exact or nearly exact duplicates.
  • Pixel Similarity: Slower, but better for catching visually similar images that may have been resized, edited, or slightly changed.
Simple rule: Start with Hash Match for a quick cleanup pass. Use Pixel Similarity later if you suspect you have resized, edited, or near-duplicate copies.

Safer cleanup workflow

If you are cleaning up an important photo library, use a cautious workflow:

  1. Scan the folder.
  2. Preview the duplicate groups.
  3. Select only the files you are confident about.
  4. Use Move Selected to move them to a temporary review folder.
  5. Open the review folder and check that nothing important was moved by mistake.
  6. Delete the review folder later only after you are sure.

Good uses for duplicate finding

  • Cleaning up old phone photo imports.
  • Finding duplicate downloads.
  • Reviewing copied folders from backups or external drives.
  • Cleaning up scanned photo projects.
  • Finding extra edited/exported versions of the same image.
  • Organizing image folders before archiving them.

What to watch out for

  • Visually similar images are not always true duplicates.
  • One image may be a higher-quality original while another is a smaller export.
  • Edited versions may contain changes you want to keep.
  • Pixel similarity can be slower on large folders.
  • When scanning subfolders, results may include files from many different locations.
