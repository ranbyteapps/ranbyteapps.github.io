What Rename Files is for

Rename Files is useful when you want a folder to have clearer, more consistent filenames. It can add prefixes, remove known prefixes or suffixes, replace text inside filenames, number files in a sequence, or build names from metadata when available.

  • Add a word or project name to the beginning of filenames.
  • Remove a prefix or suffix from filenames.
  • Find and replace text inside filenames.
  • Rename files into a numbered sequence.
  • Use padding such as 001, 002, 003 so files sort correctly.
  • Rename by metadata when supported fields are available.
  • Skip and log conflicts instead of silently overwriting files.
  • Review rename results in the Dashboard log.
Local-first note: Rename Files works on files you choose on your computer. You do not need to upload files to an online batch-renaming tool.

How to batch rename files in Grafiq

  1. Open Rename Files.
    In Grafiq, open More → Rename Files.
  2. Select files.
    Choose the files you want to rename.
  3. Choose a rename method.
    Pick the operation you want, such as Prepend Word, Remove Prefix/Suffix, Find/Replace Text, Sequential Rename, or Rename by Metadata.
  4. Enter the rename settings.
    Type the prefix, suffix, find/replace text, sequence base name, or metadata settings needed for the selected method.
  5. Review before committing if prompted.
    Make sure the resulting names look right before applying changes.
  6. Apply the rename.
    Run the rename operation.
  7. Check the Dashboard log.
    Review renamed files, skipped files, conflicts, or errors.
Safety tip: Test on a small group first. For important folders, make a copy or enable backup/versioning behavior in Grafiq Preferences before doing a large rename job.

Rename method: Prepend Word

Prepend Word adds a word or phrase to the beginning of each filename while keeping the original extension.

  • IMG_0101.jpg → Vacation-IMG_0101.jpg
  • scan001.png → FamilyArchive-scan001.png
  • clip01.mp4 → ProjectA-clip01.mp4

This is useful when you want a batch to clearly belong to a project, trip, folder, archive, or date.

Rename method: Remove Prefix or Suffix

Remove Prefix/Suffix removes a known word from the beginning or end of filenames. This is useful when cleaning up exported batches.

  • temp-IMG_0101.jpg → IMG_0101.jpg
  • draft_scan001.png → scan001.png
  • help_icon_downscaled.png → help_icon.png
  • photo_cropped.jpg → photo.jpg
Good use: Remove Prefix/Suffix is especially useful for cleaning batch suffixes such as _downscaled, _cropped, or temporary prefixes.

Rename method: Find and Replace Text

Find/Replace Text changes matching text anywhere in the filename. You can also leave the replacement blank to remove text.

  • photo (copy).jpg → photo.jpg
  • My File Name.png → My_File_Name.png
  • IMG_0101.jpg → Photo_0101.jpg
  • vacation-downscaled.jpg → vacation.jpg

This is useful for quick cleanup passes, standardizing names, removing extra words, or replacing camera filename patterns.

Rename method: Sequential Rename

Sequential Rename gives a group of files clean numbered names. This is helpful for scans, screenshots, slides, exports, and ordered image sets.

  • IMG_0101.jpg → Vacation-001.jpg
  • IMG_0102.jpg → Vacation-002.jpg
  • IMG_0103.jpg → Vacation-003.jpg

Use padding such as 3 or 4 digits so filenames sort correctly in Finder or File Explorer.

Simple rule: Use padding when numbering files. Names like 001, 002, and 003 sort better than 1, 2, and 3.

Rename method: Rename by Metadata

Rename by Metadata can build filenames from supported metadata fields when those fields are available. This is useful for photos or files you have already captioned, tagged, or organized with metadata.

  • Use date-related metadata when available.
  • Use title, description, author, or other supported fields when available.
  • Create more descriptive filenames from embedded information.
  • Skip or fall back safely when metadata is missing, depending on the workflow.

Good uses for Rename Files

  • Clean up scanned photo filenames.
  • Rename screenshots into a useful sequence.
  • Remove suffixes added by export tools, such as _downscaled or _cropped.
  • Add a project, trip, client, or archive name to a batch.
  • Standardize spaces, underscores, dashes, or camera filename patterns.
  • Prepare image sequences before building GIFs or MP4 projects.
  • Make folders easier to sort and search.

What to watch out for

  • Renaming changes filenames, not the contents of the files.
  • Make sure files are selected in the order you want before sequential renaming.
  • If a target filename already exists, Grafiq may skip the rename and log it instead of overwriting.
  • Metadata-based renaming depends on the metadata actually existing in the file.
  • Test on a small group before doing a large rename job.
  • Keep backups of important folders before major cleanup work.
