Grafiq

Grafiq is a local-first desktop toolbox for everyday image, video, GIF, metadata, and file cleanup tasks.

It is built for people who want useful desktop tools without subscriptions, accounts, ads, uploads, watermarks, or data harvesting.

Grafiq is designed like an old-school utility: choose your files, choose a tool, export the result.

Photos & Images

  • Manage Metadata: Edit captions, descriptions, and metadata for supported files.
  • Background Remover: Remove image backgrounds locally and refine difficult areas.
  • Crop Studio: Crop images, animated GIFs, and videos with aspect presets, batch apply, and clean exports.
  • Photo Splitter: Split one scanned image or scanned PDF page containing multiple printed photos into separate cropped JPG or PNG files.
  • Upscaler: Enlarge images or videos using classic scaling or built-in local AI models; no API keys required.
  • Black & White Tools: Convert or process images and videos in grayscale/black-and-white workflows.
  • Redactor: Blur, hide, pixelate, crop, spotlight, highlight, or mark up sensitive image content.
  • Find Image Duplicates: Detect visually similar or duplicate images.

Video, GIF & Graphics

  • Video Tools: Trim, rotate, reorder, combine, mute, add audio overlays, and create picture-in-picture style video overlays.
  • GIF Tools: Preview, build, convert, extract frames, add captions, and work with animated GIFs.
  • Motion Effects: Apply motion-style visual effects to supported media.
  • Cinematic Slideshow: Play media in a fullscreen-style slideshow with overlays and transitions.
  • SVG Tools: Preview, edit, batch convert, and export SVG graphics.
  • Converter: Convert supported image files and videos into common output formats.
  • Downscaler: Reduce the file size of your image and video files.

Organization & Search

  • Organizer: Copy or move files by date, type, folder, and extension with preview and optional renaming.
  • Rename Files: Batch rename files using patterns, metadata, or sequence rules.
  • AI Metadata Search: Search folders using AI-assisted metadata and descriptions. Experimental feature.
  • Run CLI Panel: Use safe in-app commands for folder analysis and organization. Experimental feature.

Privacy

Grafiq is designed to process files locally by default. It does not require accounts, ads, subscriptions, watermarks, or data harvesting.

Optional internet or AI features are user-initiated. Grafiq does not send your files to Ranbyte Apps. The only exception is if you choose to email or share files with us for support.
