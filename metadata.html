What metadata is

Metadata is information stored about a file. For photos, this may include details such as a description, caption, author, copyright, keywords, software, timestamps, camera information, and GPS-related fields.

Metadata can be useful for organization and search, but it can also reveal information you may not want to share publicly.

Privacy tip: Before posting or sending images publicly, it is worth checking whether the file contains author, location, description, copyright, or other embedded metadata you do not want to include.

How to edit full image metadata on a JPEG

  1. Open Edit Full Image Metadata.
    In Grafiq, choose File → Edit Full Image Metadata.
  2. Select a JPEG file.
    Choose a .jpg or .jpeg image.
  3. Review the available fields.
    Common fields may include Title / Description, Author, Copyright, Software, Keywords, and GPS Latitude / GPS Longitude.
  4. Edit or clear the fields you want to change.
    Update the metadata you want to keep, or remove fields you do not want included.
  5. Save the metadata.
    Click Save Metadata.
Safer workflow: When you are learning the tool, enable backups or write-to-copy behavior in Grafiq Preferences so you can preserve your original files.

How to add or edit a photo caption

  1. Open Image Caption & Overlay.
    Use File → Image Caption & Overlay, or use the keyboard shortcut if configured in your build.
  2. Choose the image or images.
    Use the single-image or multiple-image workflow depending on whether you are editing one file or a batch.
  3. Enter the caption or description.
    Grafiq can write the caption into the image description/caption metadata field when supported.
  4. Optionally write a visible overlay copy.
    If you want the caption burned into the image pixels, use the overlay option or related Preferences.
  5. Save or export the result.
    Check the output folder and Dashboard log for saved results.

How to search metadata across a folder

  1. Open Metadata Explorer.
    Choose File → Metadata Explorer or the Metadata Explorer shortcut in Grafiq.
  2. Choose a folder to search.
    Select the folder containing the files you want to inspect.
  3. Enter a search term.
    Search for a word, phrase, author, caption, description, tag, or other supported metadata value.
  4. Include subfolders if needed.
    Turn on Include subfolders when your media is stored in nested folders.
  5. Start the search.
    Grafiq lists matching files. If clickable paths are enabled, you can open or reveal results from the log.
  6. Export or act on results.
    Use CSV/TXT export or copy/move selected files if you are organizing a collection.

CSV metadata workflows

CSV workflows are useful when you want to review or edit metadata in a spreadsheet.

  • Export Metadata to CSV: Save filenames and editable metadata fields to a spreadsheet-friendly file.
  • Import Metadata from CSV: Apply descriptions and optional renames from a CSV file.
  • Suggested CSV columns: filename, description, and optional new_filename.
  • Best practice: Test on a small group first and keep backups enabled while learning.

Metadata cleanup vs. redaction

Editing metadata and redacting image pixels are different jobs.

  • Use metadata tools when you want to edit hidden file information such as captions, author, keywords, copyright, or GPS-related fields.
  • Use Redactor when you want to hide visible information inside the image, such as names, addresses, account numbers, faces, or license plates.
  • Use Strip EXIF in Redactor when saving a privacy-focused image copy and you want embedded metadata omitted from that exported file.

What to watch out for

  • Different file formats support different metadata fields.
  • Some workflows are JPEG-specific, especially full image metadata editing.
  • Clearing GPS-related fields does not remove visible location clues inside the image itself.
  • If you remove metadata, keep an original copy if you may need that information later.
  • When sharing publicly, check both visible image content and embedded metadata.
