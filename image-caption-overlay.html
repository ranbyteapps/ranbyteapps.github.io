What Image Caption & Overlay is for

Image Caption & Overlay is useful when you want to add visible text to an image. This is different from metadata captions, which are stored inside the file. Overlay text becomes part of the exported image itself.

  • Add visible captions to images.
  • Add labels, notes, dates, names, or titles.
  • Create simple tutorial or instruction images.
  • Add text overlays to screenshots.
  • Prepare labeled family archive images.
  • Create quick graphics without opening a large design app.
  • Save a new edited copy while keeping the original image unchanged.
Local-first note: Image Caption & Overlay works on your computer. You do not need to upload private photos or screenshots to an online captioning tool.

  1. Open Image Caption & Overlay.

Simple rule: Keep captions short. A short caption is easier to read and less likely to cover the important part of the image.

Visible captions vs. metadata captions

Grafiq can help with both visible captions and metadata, but they are not the same thing.

  • Visible caption: Text is drawn directly on the image and will be seen by anyone who opens the exported copy.
  • Metadata caption: Text is stored inside the file metadata and may not be visible unless an app reads that metadata.
Good workflow: Use visible captions when the viewer needs to see the text immediately. Use metadata captions when you want searchable or embedded descriptions without changing how the image looks.

Good uses for image captions

  • Add names and dates to old family photos.
  • Add labels to scanned archive images.
  • Add instructions to screenshots.
  • Create simple before-and-after images.
  • Add a title to a photo for a slideshow.
  • Add product labels or quick notes.
  • Create lightweight tutorial graphics.
  • Make images easier to understand when shared outside the original folder context.

Tips for readable captions

  • Use short text whenever possible.
  • Place captions in an area with simple background.
  • Use high contrast between text and the image.
  • Use an outline or background behind text if the image is busy.
  • Avoid covering faces, important details, or document text.
  • Preview at the size where the image will actually be viewed.

Caption ideas

  • Names: Mom and Dad, 1978
  • Dates: Summer 1984
  • Places: Grand Canyon Trip
  • Instructions: Click Export after choosing the folder
  • Project labels: Before, After, or Step 3
  • Archive notes: Scanned from family album

How to use captions with other Grafiq tools

  • Use Photo Splitter first, then caption each separated photo.
  • Use Metadata Explorer to find images, then add visible captions to selected copies.
  • Use Redactor before captioning if private details need to be hidden.
  • Use Crop Studio before captioning if the image needs better framing.
  • Use Cinematic Slideshow after captioning if you want labeled images in a video sequence.

What to watch out for

  • Visible captions become part of the exported image.
  • Text can cover important image details if placed poorly.
  • Small text may be hard to read after resizing or sharing.
  • Busy backgrounds can make text hard to read without a text background or outline.
  • Use metadata editing instead if you want a hidden searchable caption rather than visible text.
  • Keep the original image unchanged until you confirm the captioned export looks right.
