What Downscaler is for

Downscaler is useful when a file is larger than you need. It can reduce dimensions, compression, or video size targets so the exported copy is easier to store, send, upload, or use in another project.

  • Open a single image or video file.
  • Open multiple files for batch downscaling.
  • Work with images and videos in the same batch workflow.
  • Adjust the reduction amount with a simple slider.
  • Preview the current file before final export.
  • See estimated output information such as size and dimensions.
  • Export a single file or apply settings to a whole batch.
  • Keep original files unchanged.
Local-first note: Downscaling happens on your computer. You do not need to upload private photos or videos to an online compression website.

How to make one image or video smaller

  1. Open Downscaler.
    In Grafiq, open More → Downscaler.
  2. Open a file.
    Click Open File… and choose the image or video you want to reduce.
  3. Adjust the reduction amount.
    Use the Reduce slider. Lower values make lighter changes; higher values make stronger reductions.
  4. Check the estimate.
    Watch the estimated output information for size, dimensions, and video bitrate targets when available.
  5. Preview the current file.
    Click Preview (Current). For images, the preview updates in the app. For videos, Grafiq creates a short sample preview using the current settings.
  6. Export the smaller copy.
    Click Apply (Save…) [Single] and choose where to save the new file.
  7. Review the result.
    Open the exported file and confirm that the size and quality are acceptable.

How to downscale a batch of files

  1. Open Downscaler.
    In Grafiq, open More → Downscaler.
  2. Open multiple files.
    Click Open Files… (Batch) and select the files you want to reduce.
  3. Review files with Prev and Next.
    Use Prev and Next to move through the selected files and check the preview.
  4. Set the reduction level.
    Adjust the Reduce slider until the estimate looks reasonable.
  5. Choose batch options.
    Set the output suffix if available. If you want to preserve folder structure, use the option to keep original folders when available.
  6. Choose an output folder.
    Click Apply Batch (Save Folder …) and choose where the smaller files should be saved.
  7. Check the exported batch.
    Review the output folder and open a few files to confirm quality.

  • Reduce file size before archiving a large folder.

Simple starting settings

File size and quality are a tradeoff. A stronger reduction usually means a smaller file, but it can also make the image or video softer.

  • Start around a moderate reduction for photos and preview the result.
  • If the file is still too large, increase the reduction amount.
  • If the image or video looks too soft, reduce less.
  • For important files, export one test file before running a large batch.
  • Keep the original files until you know the smaller copies are good enough.
Simple rule: Preview one representative file first. Once you like the result, use the same settings for the rest of the batch.

Video downscaling notes

Video files usually take longer than images because they need to be re-encoded. Grafiq can show video size estimates and create short preview samples so you can check the result before exporting a full file.

  • Large videos can take time to process.
  • Lower bitrate usually means smaller files, but too low can create visible compression artifacts.
  • Rotation options can help when a video has orientation metadata or appears sideways.
  • Preview a short sample before exporting a long video.

What to watch out for

  • Downscaling reduces size; it does not improve image or video detail.
  • Strong reduction can make text, faces, or fine details softer.
  • Video exports re-encode the file, so quality and size may change.
  • Very large files or batches can take time.
  • Always check important exported files before deleting or archiving originals.
