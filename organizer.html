What Organizer is for

Organizer is useful when you want to clean up a folder by copying or moving matching files into a new location. It is especially helpful for Downloads folders, screenshot folders, scanned photo projects, media folders, and large mixed folders.

  • Choose a source folder to scan.
  • Include subfolders when needed.
  • Filter files by time range.
  • Use presets such as All Files, Today, Yesterday, Last 24 Hours, Last 7 Days, or Custom.
  • Filter by file type such as images, videos, screenshots, or custom extensions.
  • Preview matching files before copying or moving anything.
  • Copy files while leaving originals in place.
  • Move files when you are ready to actually clean up the source folder.
  • Create an optional new subfolder inside the destination.
  • Optionally rename files sequentially during copy or move.
Local-first note: Organizer works on folders you choose on your computer. You do not need to upload files to an online organizing or cleanup service.

How to organize files in Grafiq

  1. Open Organizer.
    In Grafiq, open More → Organizer.
  2. Choose a source folder.
    Select the folder you want Grafiq to scan.
  3. Include subfolders if needed.
    Enable Include Subfolders if the files you want are inside nested folders.
  4. Choose a time range.
    Pick a preset such as All Files, Today, Yesterday, Last 24 Hours, Last 7 Days, or Custom.
  5. Choose a file type.
    Filter by All Files, Images, Videos, Screenshots, or Custom Extensions.
  6. Choose a destination folder.
    Select where matching files should be copied or moved.
  7. Optionally create a new subfolder.
    Enter an optional new subfolder name if you want Organizer to create a folder inside the destination.
  8. Choose Copy or Move.
    Use Copy when testing or when you want originals left in place. Use Move when you are ready to relocate files.
  9. Preview first.
    Click Preview to see matching files before making changes.
  10. Run the organizer action.
    After reviewing the preview, run the copy or move action.
Simple rule: Start with Copy and use Preview. Once you trust the filter settings, you can use Move for real cleanup.

How to use custom extensions

Custom extensions are useful when you only want to collect certain file types.

  1. Choose Custom Extensions.
    In the file type filter, choose Custom Extensions.
  2. Enter the extensions you want.
    Use extensions such as .png, .jpg, .mp4, .pdf, or a comma-separated list like .png, .jpg, .mp4.
  3. Preview matches.
    Run Preview to confirm the filter is catching the right files.
  4. Copy or move the results.
    Choose the action only after the preview looks correct.

How to rename files sequentially while organizing

Organizer can optionally rename files during the copy or move operation. This is useful for screenshots, scanned photos, exports, or batches that need cleaner names.

  1. Enable Rename Sequentially.
    Turn on the sequential rename option.
  2. Choose a base name.
    Enter a base name such as screenshots, vacation, scans, or project.
  3. Choose a start number.
    Pick the first sequence number.
  4. Choose padding.
    Use padding such as 3 digits so files sort cleanly, for example 001, 002, 003.
  5. Preview and run.
    Preview the matched files first, then copy or move them with the new names.

Good uses for Organizer

  • Move screenshots from a cluttered folder into a dedicated screenshot folder.
  • Copy recent photos or videos from Downloads into a project folder.
  • Collect image files from nested folders into one destination.
  • Separate videos from a mixed media folder.
  • Collect scanned photo exports into a clean folder.
  • Find files modified in the last day or week.
  • Batch rename copied files into a clean numbered sequence.
  • Prepare files before using other Grafiq tools such as Converter, Downscaler, Photo Splitter, or Metadata Explorer.

Copy vs. Move

  • Copy: Leaves original files where they are and creates copies in the destination folder. Best for testing.
  • Move: Relocates matching files to the destination folder. Best after you trust the preview results.
Safer workflow: When working with important files, use Copy first. After reviewing the copied results, delete or move originals manually only when you are sure.

What to watch out for

  • Preview results before copying or moving files.
  • Include Subfolders can pull files from many nested locations.
  • Move changes where files live, so use Copy first if you are unsure.
  • Custom extension filters depend on the file extension, not the actual content of the file.
  • Sequential renaming is useful, but make sure the order and destination are correct before running a large batch.
  • Keep backups of important folders before large cleanup jobs.
