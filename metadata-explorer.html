What Metadata Explorer is for

Metadata Explorer is useful when you want to look inside image files and search for embedded information. Instead of opening one file at a time, you can scan a folder and review the metadata that Grafiq finds.

  • Search image metadata across a selected folder.
  • Review embedded captions, descriptions, authors, software names, keywords, dates, or other available fields.
  • Look for privacy-sensitive fields before sharing images.
  • Find images that contain specific words or metadata values.
  • Use metadata information to help organize photo archives.
  • Export metadata results to CSV where available.
  • Work locally without uploading images to an online metadata viewer.
Local-first note: Metadata Explorer works on folders you choose on your computer. You do not need to upload private photos or archives to an online metadata search tool.

What image metadata can include

Metadata depends on the file, camera, app, scanner, editor, and format. Not every file has the same fields. Some images may have a lot of metadata, while others may have very little.

  • Title or caption fields.
  • Description or comment fields.
  • Author or creator fields.
  • Copyright information.
  • Software or app names.
  • Keywords or tags.
  • Date and time fields.
  • Camera or device information.
  • GPS latitude and longitude fields where present.
Important: Metadata varies by file. A missing field does not always mean something went wrong — the file may simply not contain that metadata.

How to search image metadata in Grafiq

  1. Open Metadata Explorer.
    In Grafiq, open More → Metadata Explorer, or open it from the metadata tools area if available in your build.
  2. Choose a folder.
    Select the folder that contains the images you want to inspect.
  3. Include subfolders if needed.
    Enable subfolder scanning if your images are stored inside nested folders.
  4. Enter a search term.
    Search for a word, name, caption, keyword, software name, location text, or other metadata value.
  5. Run the search.
    Let Grafiq scan the selected folder and show matching files.
  6. Review the results.
    Open or inspect matching files to confirm which metadata fields matched your search.
  7. Export results if needed.
    Use CSV export if you want a spreadsheet-friendly record of the metadata search results.

How to use Metadata Explorer for privacy review

Metadata can sometimes reveal information you did not intend to share. Metadata Explorer can help you inspect files before sending or publishing them.

  1. Choose the folder you plan to share from.
    Select the folder that contains images you may upload, email, or post.
  2. Search for sensitive fields.
    Look for GPS, location, device, author, software, name, project, or caption information that might matter.
  3. Inspect matching files.
    Review the files that contain metadata you care about.
  4. Use the right cleanup tool.
    Use Grafiq metadata editing or Redactor’s Strip EXIF workflow when you need to remove or reduce embedded metadata before sharing.
  5. Check the exported copy.
    After cleanup, inspect the exported file again before sharing.
Privacy reminder: Metadata cleanup is different from visual redaction. Removing metadata does not hide information that is visibly shown inside the image itself.

How to use Metadata Explorer for archives

Metadata Explorer can also help with photo archive projects, especially when you are captioning, scanning, or organizing large folders.

  • Find photos that mention a person’s name.
  • Find images with a certain caption or keyword.
  • Check which files already have descriptions.
  • Look for files created or edited by a certain app.
  • Find images that still need metadata cleanup.
  • Export metadata to CSV for a spreadsheet-based review.

Good search ideas

  • Search for a family name, project name, event name, or location.
  • Search for GPS, latitude, or longitude when checking location metadata.
  • Search for camera or software names if you are sorting files by source.
  • Search for keywords you previously added to image files.
  • Search for copyright or author names.
  • Search for terms from captions or descriptions.

Metadata Explorer vs. Metadata Editor

  • Metadata Explorer: Best for searching and reviewing metadata across a folder.
  • Metadata Editor: Best for editing metadata on supported files.
Good workflow: Use Metadata Explorer to find files that need attention. Then use metadata editing or Redactor’s Strip EXIF option when you need to change or remove metadata.

What to watch out for

  • Not all image formats store metadata the same way.
  • Some images may contain little or no metadata.
  • Different apps may use different metadata fields for captions, descriptions, or keywords.
  • Metadata search does not detect information visibly shown inside the image.
  • CSV export is useful for review, but check important files directly before sharing.
  • Keep originals until you confirm any edited or cleaned copies are correct.
