What GIF Tools is for

GIF Tools is useful when you want to inspect, convert, rebuild, caption, or repurpose animated GIFs and image sequences. It is also useful when you want to make a simple MP4 from still images without opening a large video editor.

  • Preview animated GIFs before making changes.
  • Extract the first frame from a GIF as a still image.
  • Export all GIF frames as separate image files.
  • View GIF metadata.
  • Build GIFs from image frames or standalone images.
  • Build GIFs from video clips.
  • Convert animated GIFs to MP4.
  • Add or edit captions on GIF frames.
  • Build MP4 videos from selected images with timing, pan/zoom, transitions, preview, and project save/load.
Simple rule: Use GIF for short looping animations. Use MP4 when the animation is longer, larger, more detailed, or needs easier playback on websites and devices.

How to convert a GIF to MP4 in Grafiq

  1. Open GIF Tools.
    In Grafiq, open GIF Tools from the sidebar or choose File → GIF Tools.
  2. Choose the GIF.
    Under Choose a GIF to work with, click Browse and select your animated GIF.
  3. Preview the GIF.
    Click Preview GIF to make sure you selected the right file. Adjust Preview Speed (%) if you want to inspect it more slowly or quickly.
  4. Convert to MP4.
    Click Convert to MP4.
  5. Choose where to save.
    Pick the output location when prompted.
  6. Check the result.
    Open the exported MP4 and confirm that timing and playback look right.

How to extract frames from a GIF

  1. Open GIF Tools.
    Open GIF Tools and browse to your GIF.
  2. Preview the GIF.
    Use Preview GIF to confirm you have the correct file.
  3. Choose a frame export option.
    Use Extract First Frame if you only want the opening frame as a still image. Use Export All Frames if you want every frame saved out as separate image files.
  4. Review the exported files.
    Check the output folder and confirm that the frames exported as expected.

How to build a GIF from images

  1. Open GIF Tools.
    Open GIF Tools from the sidebar or File menu.
  2. Choose the correct build option.
    Use Build GIF from Images when you have standalone image files. Use Build GIF from Frames when you already have a numbered image sequence.
  3. Select your images.
    Add the images or frames you want to include.
  4. Reorder frames if needed.
    Put the images in the order you want before exporting.
  5. Export the GIF.
    Save the new animated GIF and preview it to make sure the sequence looks right.

How to build a GIF from a video clip

  1. Open GIF Tools.
    Open GIF Tools.
  2. Choose Build GIF from Video.
    Select the video file you want to turn into a GIF.
  3. Choose the clip section.
    Set the start time, end time, and FPS for the GIF.
  4. Export and preview.
    Save the GIF and preview the result.

How to add captions to a GIF

  1. Open GIF Tools and choose a GIF.
    Browse to the animated GIF you want to caption.
  2. Open Caption Editor.
    Click Caption Editor.
  3. Add or edit captions.
    Enter the caption text you want to appear on the GIF frames.
  4. Export the captioned GIF.
    Save the result and preview it before sharing.

How to build an MP4 from images

  1. Open GIF Tools.
    Open GIF Tools and choose Build MP4 from Images.
  2. Add images.
    Select the images you want to use as slides.
  3. Put the slides in order.
    Move slides up or down and remove anything you do not want in the final video.
  4. Set timing and motion.
    Adjust per-slide duration, transition settings, pan/zoom mode, transition duration, pan/zoom duration, and zoom amount.
  5. Preview the project.
    Use Preview to check the timing and motion before building the final MP4.
  6. Save the project if needed.
    Use Save Project… if you want to come back and edit the slideshow later.
  7. Build the MP4.
    Click Build MP4 and choose where to save the video.

Good uses for GIF Tools

  • Turn a GIF into an MP4 for easier sharing.
  • Extract GIF frames for review, editing, or reuse.
  • Create short GIFs from a few images.
  • Turn a short video clip into a GIF.
  • Add captions to simple GIF tutorials.
  • Create a quick MP4 slideshow from still images.
  • Preview GIF timing before exporting changes.

What to watch out for

  • GIFs use a limited color palette, so large or detailed animations may look banded.
  • Long GIFs can become very large files. MP4 is usually better for longer animations.
  • Very large GIFs or very large source images may take longer to process.
  • Always preview timing before exporting a final GIF or MP4 project.
  • Reorder frames or slides before exporting if sequence matters.
